# Sinergia

Sinergia es un prototipo de una plataforma para que estudiantes puedan compartir ideas, publicar temas de interés y encontrar personas con quienes realizar proyectos. Su diseño reúne distintas secciones, como el inicio, los perfiles, las publicaciones, los mensajes y la configuración.

Esta versión utiliza HTML para organizar el contenido, CSS para el diseño y un archivo JavaScript externo para incorporar interacciones básicas. Es una demostración académica y los datos se guardan localmente en el navegador.

## Funciones principales

- Inicio de sesión de demostración.
- Creación de publicaciones mediante un formulario.
- Almacenamiento de publicaciones en un arreglo de objetos.
- Visualización dinámica de publicaciones.
- Botón para dar Me gusta y actualizar su cantidad.
- Opción para eliminar publicaciones.
- Filtros por tipo y categoría.
- Búsqueda de publicaciones.
- Cambio entre tema claro y oscuro.

## Cómo abrir el proyecto

1. Descarga y descomprime la carpeta del proyecto.
2. Abre la carpeta en Visual Studio Code.
3. Ejecuta el archivo `index.html` con Live Server.
4. Selecciona la opción para iniciar sesión e introduce las credenciales de demostración.
5. En la sección de publicaciones puedes probar los filtros, los Me gusta y la eliminación. En Crear publicación puedes agregar contenido nuevo.

## Archivos principales

- `index.html`: página pública de entrada.
- `styles.css`: estilos y adaptación visual.
- `script.js`: funciones e interacciones básicas.
- `sinergia/`: páginas internas y secciones informativas.

## Alcance

Las publicaciones y el tema se guardan en el almacenamiento local del navegador. La sesión de demostración se mantiene en la pestaña actual. No existe una base de datos ni un servidor que comparta información entre dispositivos.

Las demás secciones conservan su presentación visual, pero no todas cuentan con funciones reales. La cuenta de demostración y los datos de ejemplo no deben utilizarse como un sistema de seguridad o un servicio público.
