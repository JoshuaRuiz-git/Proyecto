Bienvenido a Sinergia

Sinergia es una red social para estudiantes y profesionales que quieren encontrar compañeros de colaboración. No es una aplicación de citas.

Su propósito es conectar personas para realizar trabajos de colegio, proyectos universitarios, páginas web, aplicaciones, emprendimientos y colaboraciones profesionales.

Para publicar, comentar, enviar solicitudes, emparejarte o conversar necesitas una cuenta.

Cómo funciona Sinergia

  1. Cada persona indica qué domina y qué necesita aprender.
  2. La plataforma sugiere compañeros con habilidades complementarias.
  3. Cuando ambos muestran interés se produce un match y se habilita un chat de trabajo privado.
  4. La evaluación de un compañero está disponible solo después de finalizar una colaboración, con una calificación de 1 a 5 estrellas.

Así, quien domina el backend puede trabajar con quien domina el frontend, y ambos avanzan más rápido y aprenden del otro.
