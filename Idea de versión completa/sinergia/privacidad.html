Política de privacidad

Política ficticia para un prototipo académico. Describe el comportamiento previsto de esta versión de demostración. No constituye una política legal definitiva ni debe utilizarse para un servicio en producción sin revisión profesional.

Última actualización: 13 de noviembre de 2026.

1. Responsable y alcance

Sinergia es un proyecto educativo de demostración. No existe una organización comercial ni un responsable de tratamiento operativo detrás de esta maqueta. Este texto explica qué información puede quedar guardada en el navegador cuando se prueban sus funciones.

2. Información que puede guardar el prototipo

Algunas funciones utilizan el almacenamiento local del navegador para conservar preferencias y datos de prueba:

  • Cuenta de demostración: nombre, correo y contraseña utilizados para simular el acceso. En esta versión se almacenan localmente y sin el nivel de protección requerido para una aplicación real.
  • Sesión: un indicador local que permite mantener el acceso mientras se navega por las páginas del prototipo.
  • Preferencias: tema claro u oscuro y opciones de configuración seleccionadas.
  • Interacciones: reacciones, comentarios escritos en las publicaciones y mensajes de demostración.

Esta información se guarda en el navegador mediante mecanismos como localStorage y sessionStorage. No se envía a una base de datos central porque esta versión no tiene un backend conectado.

3. Uso de los datos en la demostración

Los datos locales se utilizan para mostrar que se pueden mantener preferencias, recordar interacciones y presentar una experiencia de navegación más completa. Los ejemplos no se utilizan para publicidad, elaboración de perfiles comerciales ni decisiones automatizadas sobre personas reales.

4. Fotografías y recursos externos

Algunas fotografías se cargan desde direcciones de images.unsplash.com. Para mostrarlas, el navegador solicita el recurso al proveedor externo. Esa solicitud puede implicar el intercambio de información técnica habitual de conexión, conforme a las políticas del proveedor. Las imágenes son ilustrativas y no identifican necesariamente a los perfiles ficticios del sitio.

5. Contraseñas y seguridad

La autenticación de esta maqueta no es segura para uso real: las cuentas y contraseñas de prueba se almacenan en el propio navegador. Por ello, se recomienda utilizar únicamente las credenciales de demostración y nunca introducir contraseñas reutilizadas o información sensible. Una versión de producción necesitaría autenticación del lado del servidor, contraseñas protegidas mediante hash seguro, controles de acceso y medidas adicionales de seguridad.

6. Conservación y eliminación de la información

Los datos permanecen en el navegador hasta que se sobrescriben o la persona usuaria los elimina. Se pueden borrar desde las opciones del navegador, utilizando la función para eliminar los datos del sitio o el almacenamiento local. Si se utiliza una ventana privada, el navegador puede eliminar estos datos al cerrar la sesión privada.

7. Compartición de información

El prototipo no dispone de un servidor para compartir perfiles, mensajes o comentarios con otras personas. Los datos de interacción que se guardan localmente no se sincronizan entre dispositivos. La única comunicación externa prevista por el diseño actual es la solicitud de fotografías alojadas por el proveedor de imágenes.

8. Derechos y controles de la persona usuaria

En esta demostración, la persona usuaria puede revisar y eliminar los datos locales mediante las herramientas del navegador. No existe todavía un mecanismo operativo para atender solicitudes formales de acceso, rectificación, eliminación o portabilidad. En una versión real se deberán habilitar canales para ejercer los derechos que correspondan según la normativa aplicable.

9. Privacidad de menores y datos sensibles

Este prototipo no debe utilizarse para recopilar datos reales de menores, información médica, financiera, documentos de identidad, ubicación precisa ni otros datos sensibles. Para un lanzamiento real se deberán definir medidas adecuadas de consentimiento, protección y uso según la edad de las personas usuarias y la legislación aplicable.

10. Cambios a esta política

El contenido puede actualizarse mientras se desarrolla el proyecto. Una versión real debe indicar qué cambió, cuándo entra en vigor y cómo se informará a las personas usuarias.

11. Contacto y naturaleza del documento

No hay un canal de privacidad operativo porque Sinergia es una maqueta sin backend. Antes de publicar un servicio real, se deberá identificar al responsable, facilitar un medio de contacto y solicitar una revisión profesional de esta política. Este texto tiene únicamente un propósito demostrativo.
