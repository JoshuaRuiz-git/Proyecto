# Sinergia

Sinergia es una plataforma de colaboración pensada para que estudiantes y personas con intereses similares puedan conocerse, compartir conocimientos y encontrar compañeros para desarrollar proyectos. La idea principal es conectar habilidades complementarias y facilitar el trabajo en equipo.

## Qué permite hacer

- Crear y editar un perfil personal con información y habilidades.
- Consultar perfiles de otros miembros y descubrir personas cercanas.
- Crear publicaciones, seleccionar su categoría, reaccionar y comentar.
- Buscar publicaciones y aplicar filtros.
- Enviar y gestionar solicitudes de amistad.
- Consultar matches de colaboración y mantener conversaciones.
- Cambiar entre tema claro y oscuro.
- Configurar preferencias y ubicación de forma manual.
- Completar evaluaciones de colaboración y consultar la reputación mostrada en los perfiles.
- Consultar las páginas informativas, los términos y la política de privacidad.

## Tecnologías

El proyecto utiliza HTML para la estructura de las páginas, CSS para el diseño y JavaScript para las interacciones. La información de demostración se conserva en el navegador mediante `localStorage` y `sessionStorage`.

## Cómo abrirlo

1. Descarga y extrae la carpeta del proyecto.
2. Abre la carpeta `Sinergia_Completa` en Visual Studio Code.
3. Ejecuta `index.html` con Live Server.
4. Utiliza la cuenta de demostración para entrar a las secciones privadas.

## Organización de los archivos

- `index.html`: página pública de inicio.
- `styles.css`: estilos, componentes y adaptación a distintos tamaños de pantalla.
- `script.js`: lógica de la aplicación, eventos, almacenamiento y contenido dinámico.
- `sinergia/`: páginas internas, perfiles de ejemplo y páginas informativas.

## Alcance del proyecto

Sinergia es un prototipo de frontend. Las cuentas, publicaciones, reacciones, comentarios, preferencias, evaluaciones y conversaciones funcionan con datos guardados en el navegador. No cuenta con un servidor ni una base de datos compartida, por lo que la información no se sincroniza entre dispositivos. La cuenta de demostración tampoco representa un sistema de autenticación seguro para producción.

Las fotografías remotas requieren conexión a Internet. Los perfiles, publicaciones y conversaciones de ejemplo son datos demostrativos.
